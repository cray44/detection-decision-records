# Example 01 — PsExec Admin Suppression

**Archetype:** High-volume process_creation FP from a known-benign parent chain  
**Decision:** `suppress`  
**Rule:** PsExec Tool Execution (Windows, `process_creation`)

## Scenario

IT Operations uses PsExec via SCCM (`ccmexec.exe` parent) for patch deployment and remote diagnostics. This generates ~40 alerts/day with a 100% FP rate from the management VLAN.

The suppression is scoped to the two known SCCM parent binary paths. PsExec invocations from shells, scheduled tasks, or WMI parents are **not** suppressed — those are attacker-shaped.

## Files

## Reproducing the filter export

```bash
ddr export-sigma-filter ddr.yml
```

## Key design notes

- `tuning.condition: not known_fp_sccm_agent` — the suppression is an exclusion, not a match
- `expires_on` is set 15 months out with a 180-day review cadence — long-lived but not immortal
- Evidence refs point to a Splunk saved search and the internal runbook; no log samples are embedded
